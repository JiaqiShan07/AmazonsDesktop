# 引擎通信协议

平台通过子进程的 stdin/stdout 使用 SAU 风格文本协议。任意实现以下契约的引擎均可接入；不要求使用特定算法、语言或模型。

## 传输与生命周期

- 每方独立一个引擎进程，启动时不传参数，工作目录为可执行文件所在目录。
- 指令区分大小写，每条一行，以换行结束，发送后立即 flush。管道按 UTF-8 处理；命令和坐标为 ASCII。
- stdout 只输出下文规定的响应，日志写 stderr。不要向 stdout 写提示符、空行或搜索统计。
- 加载后平台只发送 `name?`。用户点击“开始对局”后才发送 `new`，引擎不应在名称握手阶段搜索。
- 平台对完整走法校验合法性和行动方。协议错误、非法走法或进程异常退出会停止正常对局流程。
- 名称、走法及悔棋确认的响应等待上限均为 180 秒。新建棋局、替换玩家或关闭平台会终止对应进程。超时判负也会终止引擎。
- 当前协议没有时钟参数、停止搜索命令或参数协商；平台每方总时限与引擎自身预算独立。

## 坐标与走法

棋盘 10×10，黑方先行。坐标原点在**左上角**，先列后行：两轴均使用大写 `A` 到 `J`，列从左到右，行从上到下。

走法为 6 个连续字母 `X1Y1X2Y2X3Y3`：起点、终点、箭落点。移动与射箭合为一手；箭可落在刚腾空的起点。

例如 `AGAFAG` 表示界面坐标 **a4 → a5，在 a4 射箭**。比赛 TXT 使用左下角原点、小写列和数字行，与协议坐标不同，详见 [棋谱说明](records.md)。

## 基础命令

| 方向 | 行内容 | 含义 |
| --- | --- | --- |
| 平台 → 引擎 | `name?` | 查询名称 |
| 引擎 → 平台 | `name 任意名称` | 完成加载握手 |
| 平台 → 引擎 | `new black` | 初始化为黑方，并立即搜索第一手 |
| 平台 → 引擎 | `new white` | 初始化为白方，等待对手走法 |
| 平台 → 引擎 | `move AGAFAG` | 应用对手走法，随后搜索自己的走法 |
| 引擎 → 平台 | `move AGAFAG` | 返回自己的走法，引擎内部也应应用该走法 |
| 平台 → 引擎 | `end black` / `end white` | 对局结束，参数为获胜方；无需回复 |

`new` 重置棋盘、行动方和历史。平台不会把引擎自己的走法回送给它。`end` 后引擎保持存活，若支持悔棋可继续处理扩展命令。终局最后一手不一定通过 `move` 传给另一方，因为此命令还会触发搜索。

黑方引擎与人类白方的示例（箭头仅用于文档）：

```text
平台 → name?
引擎 → name ExampleEngine
平台 → new black
引擎 → move AGAFAG
平台 → move ADAEAD
引擎 → move ...
平台 → end black
```

白方引擎收到 `new white` 后不回复 `ready`，也不主动走棋；收到对手的第一条 `move` 后才返回走法。

## 可选悔棋扩展

引擎在名称末尾附加精确的能力后缀声明支持：

```text
name ExampleEngine [undo,go]
```

平台显示名称时移除该后缀。未声明的引擎可以正常对弈，但参与的引擎必须全部声明支持后才允许悔棋；平台不向旧引擎探测未知命令。

| 方向 | 行内容 | 含义 |
| --- | --- | --- |
| 平台 → 引擎 | `undo N` | 撤销引擎已观察历史中最近 N 手，不启动搜索 |
| 引擎 → 平台 | `ready` | 回退和搜索状态清理完成 |
| 平台 → 引擎 | `go` | 在本方行动时，对当前局面启动搜索 |
| 引擎 → 平台 | `move ...` | 返回 `go` 的搜索结果 |

调用前置条件：引擎已经 `new` 初始化、支持扩展且空闲；N 为正整数，不超过该引擎实际观察的历史手数。一手包含移动和射箭，N 不表示双方各走一次。

引擎应恢复棋盘、行动方、历史及与局面相关的计数；销毁整个旧搜索会话和子树，不复用回退前的树。可保留已加载模型等与局面无关的资源。完成后仅返回 `ready`，等待对手 `move` 或本方 `go`。

平台记录每个引擎实际观察的手数，分别计算回退到同一目标局面所需的 N。由于终局最后一手可能未传给另一方，双方的 N 可以不同。全部引擎回复 `ready` 后，平台才恢复本地棋盘和时钟；若恢复后的行动方为引擎，再发送 `go`。

```text
平台 → undo 2
引擎 → ready
平台 → go
引擎 → move ...
```

双人模式单次撤销一手；含引擎的模式单次撤销两手，人机模式回到人类行动方。双引擎通常只在终局空闲后可以悔棋。搜索中悔棋不在当前契约内；时钟超时后进程已关闭，需要新建棋局。
