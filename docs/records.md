# 棋谱与回放

## 原生 JSON

“保存 JSON”使用 UTF-8，无 BOM，保存对局信息和完整走法。`format` 标识棋谱格式。

```json
{
  "format": "amazons-sau-1",
  "metadata": {
    "black": "黑方",
    "white": "白方",
    "result": "先(后)手胜",
    "location": "2026-10-19 Local",
    "event": "Match"
  },
  "moves": ["AGAFAG"]
}
```

`moves` 每项是一手完整的移动与射箭，采用 [通信协议](protocol.md) 的六字母坐标。`metadata` 可省略，读取时使用默认对局信息，兼容早期 JSON 棋谱。

## 比赛 TXT

“导出比赛 TXT…”使用**严格 GB2312 编码，无 BOM**。导出前确认先后手参赛队、结果、比赛时间及地点、赛事名称。遇到 GB2312 字符集之外的字符时，平台提示修改后再导出。文件名由用户选择。

```text
#[AM][先手参赛队][后手参赛队][后手胜][2017.07.29 14:00 重庆][2017 CCGC];
1 d1i6(f9) g10g4(b4)
2 j4f8(b8) a7e3(h6)
```

首行为对局注释，以 `#` 开始、`;` 结束；方括号和换行作为格式分隔符，字段内容应避开这些字符。后续每行是一回合：回合数、黑方着法、白方着法。编号从 1 连续递增，最后一回合允许只有黑方着法。

坐标原点在**左下角**，列 a–j、行 1–10。`d1i6(f9)` 表示 d1 移至 i6，箭落 f9。命令和分隔符均为英文字符。平台显示坐标与 TXT 一致，和协议的上方原点坐标分别转换。

读取 TXT 按 GBK 解码，兼容 GB2312 以及已有的 GBK 棋谱；新导出始终严格使用 GB2312。导入时检查格式、回合顺序及全部走法合法性。

## 回放与继续对局

JSON 与 TXT 均可直接打开回放。回放期间时钟停止，支持开局、上一步、播放/暂停、下一步、终局及进度条跳转；自动播放每秒推进一手。回放期间保存或导出时，范围为整份棋谱。

“从此处继续”保留当前位置之前的走法，转为本地双人准备状态，并重置双方时钟；点击“开始对局”后开始计时。

正常对局悔棋会同步恢复局面与计时，并清除旧比赛结果。引擎同步流程见 [通信协议](protocol.md#可选悔棋扩展)。
